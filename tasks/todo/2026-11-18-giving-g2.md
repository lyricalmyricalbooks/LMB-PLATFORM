# Donations & tips, part two: fundraisers (G2, Beta)

From the approved plan "Four more ways to sell" (https://claude.ai/artifact/AJtw9ihHaKAg4B7EtBva9N), Giving G2: a
fundraiser with a goal, a last day and the owner's story on the Support page, a bar that fills as gifts come in, a
supporters wall, rewards and updates to supporters. Split in three pull requests.

## G2a: the fundraiser itself
- [x] `src/shared/fundraiserRules.ts` (server copy generated): the owner's form (`cleanFundraiser`: name 3 to 80 letters,
      goal $100 to $1,000,000, last day today to a year out, story up to 5,000 letters, wall on or off), state
      (draft, live to the end of its last day, ended), days left, the bar, the wall (one line per gift, newest first,
      at most 60) and what anyone may see (`publicFundraiser`: never gift ids or emails).
- [x] `functions/giving.js`: `fundraisers/{id}` (server only). The server adds each paid gift to the total and the
      supporter count inside the paid transaction, and takes a refunded one back off, wall line included. `givingInfo`
      sends the running one and the shop's day; `giftStart` takes `fundraiserId` (only the running one, else 409
      `fundraiser_ended`) and `wall`; owner ops `saveFundraiser` (one runs at a time; an ended one stays as it was) and
      `endFundraiser` (a draft is deleted).
- [x] Rules emulator: fundraisers closed to browsers, with a two-shop check.
- [x] Admin › Donations: Fundraiser section (running card with bar, Edit, End now; past ones in one line each; drawer with
      name, goal, last day, story, wall switch, Save as draft / Start fundraiser). Gifts to it carry a Fundraiser badge.
- [x] Support page: the fundraiser's name as the heading, raised of goal, bar, supporters, days left, story, wall, and a
      "Show my name on the supporters wall" tick. A fundraiser that ends while the page is open: the gift goes to the
      shop after the giver sees why. Regions `supportFundraiser`, `supportWall`; words in Text & labels › Support page
      (English and French). Studio shows a sample fundraiser with `fundraiser=sample` on its address.
- [x] Home: a Fundraiser card after To do while one runs.
- [x] Admin fixture: a running fundraiser and a past one; save and end work in memory.
- [x] Tests: shared rules (both copies), server (5 cases), admin view, Support page rules.
- [x] Verified: screenshots of Donations, the drawer, Home and the Support page on desktop and phone.
