
## A simpler flow (3 November 2026, Julian: "more elegant solutions")

The flow above has eight screens before the admin. Three changes make it shorter without losing a function:

1. **Press name goes into the three questions.** Name, what you sell and country are one three-screen run, each step skippable. The separate "Name your press" screen goes.
2. **The record is made once, when the code is checked.** Sign-up is: email, then the six-digit code. The setup record (18.2) and the account (18.3) are created together at that moment, so there is no "account but no press" state to handle.
3. **Continue-later uses the same code.** A press that comes back gets a code again, not a second kind of link. One sign-in path for new and returning presses.

Result: email, code, three questions, admin. Five screens instead of eight, one sign-in path instead of two, and one record-creating step instead of three.

Build order is unchanged. The rows that move: 18.4 (fewer pages), 18.5 (one sign-in path). Default for the continue-later email stays off until the press asks for it.
